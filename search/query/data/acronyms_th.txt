# Each non-comment line is ONE equivalence group: whitespace-separated members
# that all denote the same thing. The FIRST member is the canonical Latin
# acronym (upper-case); the rest are its Thai transliteration and full forms.
# Expansion is symmetric — any member expands to every member of its group — so
# a query written in any of the forms becomes matchable against a document that
# indexed a different one ("pc" ⇒ also พีซี, คอมพิวเตอร์).
#
# The Latin member also drives ACRONYM RETENTION during parsing: a bare
# lower-case "it"/"pc"/"hr" that the base stop list would drop (or case-fold
# away) is recognized here and kept as the upper-case acronym, so the short,
# context-free query survives instead of collapsing to nothing.
#
# This is a GENERIC starter set. Real organizations have their own vocabulary
# (team names, product codes, internal abbreviations) — a platform injects those
# through WithAliases, which merge into these groups. Extend freely; keep one
# group per line, canonical acronym first. Lines starting with '#' are comments.
